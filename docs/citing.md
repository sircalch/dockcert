# Citing DockCert

If DockCert helps your research, please cite it. The repository's [`CITATION.cff`](https://github.com/sircalch/dockcert/blob/master/CITATION.cff) is the canonical record; GitHub's "Cite this repository" button uses it.

The all-versions DOI always resolves to the latest archived release: [10.5281/zenodo.22217570](https://doi.org/10.5281/zenodo.22217570). To cite the exact version you used, take the version DOI from the Zenodo record.

From the command line:

```bash
dockcert cite
```
